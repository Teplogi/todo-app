# ToDo リスト

Next.js で作成したシンプルな ToDo リスト Web アプリです。

## 機能

- タスクの **追加**（Enter キーでも追加可）
- **完了マーク**（チェックボックスで切替、完了率をプログレスバーで表示）
- **削除**（削除後 5 秒間は「元に戻す」が可能）
- **期限（日付）の設定**：追加時に日付指定または「今日 / 明日 / 1週間後」をワンタップで選択。追加後も期限バッジをクリックして変更・解除可能
  - 期限切れは赤、今日までは橙、近い期限は青で表示し、ヘッダーに期限切れ件数を表示
- **カレンダー表示**：月ごとに期限のあるタスクを表示（スマホではドット表示）。日付を選ぶとその日のタスク一覧を表示し、その日が期限のタスクをそのまま追加できる
- 完了済みタスクの一括削除
- 「すべて / 未完了 / 完了」での絞り込み、「追加が新しい順 / 期限が近い順」の並び替え
- タスク名のダブルクリック編集（Enter で確定、Esc でキャンセル）
- **データ永続化**：`localStorage` に保存するため、ブラウザを閉じても残ります（別タブの変更も同期）
- ダークモード・スマホ表示に対応、スクリーンリーダー向けラベル付き

## 技術スタック

- Next.js (App Router) / React / TypeScript
- Tailwind CSS
- Vercel でホスティング

## ローカルでの起動

```bash
npm install
npm run dev
```

http://localhost:3000 を開いてください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/lib/todoStore.ts` | localStorage と同期するストア（`useSyncExternalStore` 用） |
| `src/lib/date.ts` | 期限の日付計算・表示用ヘルパー |
| `src/app/TodoApp.tsx` | 画面本体（リスト／カレンダーの切り替え） |
| `src/app/components/AddTodoForm.tsx` | タスク追加フォーム（期限指定つき） |
| `src/app/components/TodoItem.tsx` | タスク 1 件の表示・完了・削除・期限変更 |
| `src/app/components/Calendar.tsx` | 月表示カレンダー |
| `src/app/page.tsx` | トップページ |
